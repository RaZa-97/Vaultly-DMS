# Vaultly

Vaultly is a self-hosted document management system for small businesses, based on [Paperless-ngx](https://docs.paperless-ngx.com/).

## Project status

Phase 1 is in progress: preparing the local project and deploying it to an Ubuntu VM through GitHub.

## Security

Real environment files and runtime data must never be committed. Copy `.env.example` to `.env` only on the deployment machine and replace every placeholder there.
