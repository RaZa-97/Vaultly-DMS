Getting started

1. Upload

Select Upload documents or drag files into the browser.

2. Process

Vaultly extracts text, runs OCR when needed, and creates a searchable record.

3. Review

Correct the title or date and add the right business metadata.

4. Find

Search inside documents or filter by tags, type, correspondent, or date.

Documents and OCR

Vaultly accepts common office documents, PDFs, and images. OCR turns text in scans and photographs into searchable content. Processing time depends on file size, page count, and enabled languages.

Search effectively

  • Search for a distinctive invoice number, customer name, or phrase.
  • Combine text search with filters for precise results.
  • Check the document’s Content tab to confirm extracted text.
Tip: clear, straight scans produce the best OCR results.

Organizing your records

Correspondents identify who sent or received a document. Document types describe what it is. Tags provide flexible labels, while custom fields store values such as account numbers, amounts, or review dates.

Use saved views for repeated searches. Keep names short, consistent, and meaningful to everyone in your business.

Storage paths

A storage path controls how archived files are named and arranged inside Vaultly-managed storage. It can contain folders, text, and supported placeholders based on document metadata.

  1. Give the path a descriptive name.
  2. Start with a simple pattern and use Preview.
  3. Confirm the preview before applying it broadly.
  4. Use forward slashes between folders and avoid reserved characters.
Continue opening and downloading managed documents through Vaultly.

Workflows

Workflows automate repeatable processing. A trigger decides when a workflow runs, conditions narrow the match, and actions update the document.

Actions can assign tags, correspondents, document types, storage paths, owners, or titles. Test a new workflow with a small sample first.

Email intake

Authorized administrators can connect a mailbox and define rules for importing attachments. Use a dedicated business mailbox, restrict accepted messages, and review processed-mail history when an expected attachment is missing.

Users and permissions

Permissions determine which areas and actions a user can access. Grant only what each role needs.

  • View allows reading.
  • Add allows creating.
  • Change allows editing.
  • Delete allows removal.

Object permissions can further limit access to particular records. Restrict configuration, logs, and user management to trusted administrators.

Configuration

Application configuration controls OCR, barcode processing, and deployment-wide behavior. Changes affect every user and may affect new processing, so administrators should record and test them carefully.

Personal Settings affect only the signed-in user.

Troubleshooting

A document is not searchable

Wait for processing, check File Tasks, inspect the Content tab, and confirm the correct OCR language is enabled.

An upload fails

Check the file type and size. If retrying fails, ask an administrator to review File Tasks and Logs.

The page does not open

Confirm the Vaultly VM is running and reachable. Administrators can check container health and System Status.

Privacy and backups

Vaultly is self-hosted, so your organization controls its server and access. Use strong individual accounts, review permissions, install trusted updates, and keep tested backups of the database, document media, and configuration secrets.

A VM snapshot alone is not a complete backup strategy. Maintain a separate recoverable backup outside the VM.

About and licenses
